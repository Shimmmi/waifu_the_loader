# Маппинг v1 → v2

Источники: `info/waifu-movers-tz.md`, `docs/tz.md` §3–9, `info/ТЗ v2 «Склад» классы, HR-режим, контракты.md` §1 и §17. Godot-ТЗ — только механики, не клиент.

| v1 | Где в коде | v2 |
| --- | --- | --- |
| Груз, кг/с от суммы power | `shared/src/economy.ts` `computeRates` | Тонны/ч `T = min(разгрузка, кран, перемещение, учёт)`. Старый тик не заменяется, пока флаг `warehouse_v2.enabled` выключен. |
| str, end, spd, cha, lck | `shared/src/schemas.ts` `STATS` | Сила, выносливость, ловкость, харизма, внимательность. Отдельный «интеллект» не добавляется: веса кладовщицы и крана сидят на `cha` и `lck`. |
| Архетип | `config/archetypes.json`, коллекция, дубликат | Характер и слот коллекции. Должность — `native_class`, не архетип. |
| Редкость N–UR, pity, звёзды | `config/economy.json`, `server/src/gacha.ts` | Те же. Фильтр биржи ×3 к классу не заменяет pity. |
| Осколки душ | `shards` | Та же валюта. Звёзды на карточке — это ранг 0–5, не осколки. |
| Билеты, жетоны, печати, монеты, протеин | `player_state` | Не сливаются. |
| Зона `warehouse` | бригада, слоты склада | Рампа, пока игрок не расставил зоны. Место на тренировке по-прежнему держится. |
| `clerk` | бонус харизмы | Кладовщица на приёмке, когда её туда ставят. Бонус клерка v1 не снимается флагом. |
| `gym` / `contract` | снятие со склада | Тренировка и курсы снимают со слота. Контракт v2 тонны ест с линии, людей не увозит. Старые контракты живут, пока флаг выключен. |
| Усталость | тренировки и заказы | На линии v2: +6/ч, ≥70 → ×0.8, 100 → простой. В тик v1 не включается. |
| Здания склад, зал, столовая, баня, автопарк, мерч, общага, диспетчерская | `config/economy.json` `buildings` | Модули: слоты, восстановление, тариф. Уровни не сбрасываются. |
| Тренировки | очки статов | Позже очки веток навыков. Сейчас без изменений. |
| Престиж «Конец смены» | печати | Остаётся. Лестница Мегапорта — отдельный прогресс тонн, не замена печатей. |
| Портрет пула при дубле | `server/src/gacha.ts` | Дубль показывает портрет уже выданной waifu. |

Доход. `cargo_per_power` 0.05 кг/с = 180 кг/ч на 1 power. Спека v2 `k_hand` 0.1 т/ч ниже этого. Функция `legacyFloorKgPerHour` не даёт часу v2 упасть ниже часа v1 на той же рампе. Эталон §5.2 считается на константах спеки, не на полу.
