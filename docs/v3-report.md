# Отчёт по этапам v3

Числа в `config/v3/` — заглушки из ТЗ. Отчёт этапа 0: [`docs/v3-audit.md`](v3-audit.md). Промпты без правки: [`docs/prompts/`](prompts/README.md). Схема обмена: [`docs/v3/content.schema.json`](v3/content.schema.json).

Игра v3 включается флагом `app_flags.v3.live`. Пока флаг выключен, старый клиент и старые маршруты работают. Новые маршруты лежат под `/api/v3/`.

## 0. Аудит

Таблица Godot-текст / v3 / код и черновик миграции лежат в `docs/v3-audit.md`. Репозитория Godot нет, списки §3 не подменены видами Godot.

## 1. Данные и ролл

Справочники в `config/v3/`. Проверка zod при старте сервера (`v3.loadV3()`). Ролл, трейты, pity и дубли — чистые функции в `shared/src/v3/engine.ts`. Тесты: 10 000 наборов трейтов, 100 000 роллов в пределах 0,3 п.п. от оценки с гарантиями, дубль держит тот же портрет.

Валюты: кредиты, звёзды, наследие. Осколки в новый кошелёк не входят. «Фокус» выключен (`banners_enabled: false`).

## 2. Пре-генерация

`tools/pregen/generate.ts`. Локальный прогон с `--approve` кладёт webp и `client/public/assets/templates/manifest.json`. Повторный запуск не перезаписывает файлы. В ролл попадают только `approved`. Вызов модели RouterAI этим скриптом не делается: ключ и бюджет остаются у автора, команда без `--approve` пишет черновики.

## 3. База

Вариант A: этажи и ячейки, 14 построек, соседство, вторая копия на 60%. Одна выработка вместо кг/с и линии терминала, когда игрок в v3. Оффлайн до 8 часов на 50%, со сводкой.

## 4. Карточки расширения

Набор фиксируется в `run_cards.pending` до выбора. Повторное расширение при открытом наборе отвечает ошибкой. Реролл, пропуск (10% цены), гарантия редкой+ после пяти пустых наборов.

## 5. Сюжет

Майлстоуны из `milestones.json`, очередь не останавливает тик, журнал на вкладке «Мир». Каждый id срабатывает один раз.

## 6. Перерождение и наследие

Порог, выручка 15% от вложений, грузчицы и звёзды остаются, постройки и кредиты забега сбрасываются. Выбор из трёх баз, одна с низким риском. Дерево из 10 узлов в `meta.json`.

## 7. Миграция и клиент

Клиент с шестью вкладками: `client/src/v3/V3App.tsx`. Включается вместе с флагом.

```bash
npm run v3:flag -- on
V3_BACKUP_DONE=yes npm run v3:migrate
```

Миграция один раз: ветераны с `legacy_portrait`, раса `terran`, класс по таблице этапа 0, редкость N…UR один к одному, уже купленный ранг копируется, в звёзды уходит только остаток осколков по курсу 1:1. Билеты, протеин, жетоны и печати в новый кошелёк не пишутся.

Отклонения от ТЗ, которые стоит поправить отдельно: локальные портреты — заглушки, не комикс-иллюстрации модели; часть эффектов карточек (авария реактора, долг мафии) хранится в JSON и влияет только через уже известные типы эффектов; «первые 30 минут смены» для трейта «Кофеиновая» считаются выполненными, отдельных фаз смены нет.
