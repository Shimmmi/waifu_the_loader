# Waifu Movers / Грузчицы Inc.

Браузерная gacha-инкрементал игра 18+ для закрытого круга. ТЗ — [`docs/tz.md`](tz.md).
Прод: <https://shimmirpgbot.ru/waifu_loader/> (вход по инвайт-коду).

Готовы этапы **M1** (склад, ресурсы, 3 здания, 10 заготовленных waifu, серверные тики и офлайн-прогресс),
**M2** (баннеры, pity, пул, дубликаты → Осколки, коллекция),
**M3** (ИИ-профили и портреты, админка) и
**M4** (все здания, тренировки, контракты, усталость, престиж «Конец смены»).

## Структура

| Папка | Что внутри |
|---|---|
| `shared/` | Типы, zod-схемы, формулы экономики, gacha и pity, процедурный генератор профилей, тесты |
| `server/` | Fastify API, миграции PostgreSQL, авторизация, серверный расчёт прогресса |
| `workers/` | BullMQ: пополнение пула waifu — процедурное (N, R и запас) и через RouterAI (SR, SSR, UR) |
| `client/` | React + Vite + Zustand, PWA |
| `config/` | Версионируемые JSON-конфиги баланса и контента (хэш пишется в `config_versions`) |
| `scripts/` | Валидатор контента, симулятор призывов, симулятор прогресса |
| `deploy/` | Dockerfile, docker-compose, конфиг Nginx, `deploy.sh`, `backup.sh`, `invite.sh` |

## Локальная разработка

Нужны Node ≥ 18.19 и Docker.

```bash
npm ci
cp .env.example .env            # заполнить POSTGRES_PASSWORD, COOKIE_SECRET и DATABASE_URL
docker compose --env-file .env -f deploy/docker-compose.yml up -d postgres redis

# API (миграции применяются при старте, заготовленные waifu попадают в пул)
cd server && SERVE_STATIC=1 PORTRAITS_DIR=../data/portraits npx tsx src/index.ts
# пул waifu: воркер раз в 60 с или разово
cd workers && npx tsx src/index.ts       # или: npx tsx src/refill-once.ts
# клиент: http://127.0.0.1:5180/waifu_loader/
npm run dev:client

npm run invite -- create 10 "тест"       # инвайт-код
```

Проверки (их же запускает GitHub Actions):

```bash
npm run lint && npm run typecheck && npm run validate -w scripts && npm test
npm run sim:gacha                         # 1 млн призывов, сверка с шансами ±0.2%
npm run sim:progress -- 10000 30          # 10 000 игроков × 30 дней
```

## Почему Docker Compose

На VPS уже живут другие сайты и их сервисы. Отдельный compose-проект `waifu_loader` со своими PostgreSQL и Redis:

- не трогает чужие базы, версии и настройки (свой Postgres 16, свой Redis с `noeviction` под очередь BullMQ);
- все порты слушают только `127.0.0.1` (API 8040, Postgres 5440, Redis 6390), наружу смотрит только Nginx;
- обновление и откат — пересборка одного образа, состояние лежит в именованных томах и `data/`;
- ограничения памяти на контейнеры не дают игре съесть ресурсы соседей.

## Деплой

```bash
./deploy/deploy.sh
```

Скрипт делает `git pull`, собирает образ, поднимает контейнеры, копирует статику клиента в `data/www`,
ждёт `/api/health`, проверяет `nginx -t` и перезагружает Nginx.

Один раз вручную:

1. В 443-блок `server` сайта `shimmirpgbot.ru` (`/etc/nginx/sites-enabled/waifu-bot`) добавить
   `include /opt/Waifu_Loader/deploy/nginx/waifu_loader.conf;`. Все location в файле с префиксом
   `^~ /waifu_loader/`, остальные пути сайта не затрагиваются.
2. Бэкапы — в cron root: `30 4 * * * /opt/Waifu_Loader/deploy/backup.sh >> /var/log/waifu_loader_backup.log 2>&1`.
   Дамп PostgreSQL и архив портретов пишутся в `/var/backups/waifu_loader`, хранятся последние 7 копий.

Инвайты на проде:

```bash
./deploy/invite.sh create 5 "друзья"     # код на 5 активаций
./deploy/invite.sh list
./deploy/invite.sh admin "Ник"           # права админа: в меню появится «ИИ-цех»
```

## Секреты

Все секреты — только в `.env` (в `.gitignore`). В репозитории лежит `.env.example` с пустыми значениями.
Ключ RouterAI живёт только на сервере (воркер и API) и никогда не отдаётся клиенту: даже каталог моделей
для админки запрашивает сервер.

## Генерация waifu через ИИ (M3)

Воркер раз в 2 минуты добирает пул ИИ-waifu редкостей SR, SSR, UR до 40 штук на редкость, начиная с самой
пустой. Одна waifu:

1. **Профиль** — текстовая модель (по умолчанию Claude Haiku — `~anthropic/claude-haiku-latest`, резервная DeepSeek V3.2) отвечает строгим JSON. Сервер проверяет его тем же
   валидатором, что и заготовки: возраст 21–55 и совпадение с текстом, стоп-лист, уникальность имени, таланты
   только из списка. Значения талантов и итоговые статы считает сервер — модель задаёт только пропорции.
   До 3 попыток, в следующую передаётся причина отказа.
2. **Портрет** — Grok Imagine 2.0, резервная Seedream 5 Flash, стиль «современное TV-аниме». Перед генерацией сервер
   выбирает образ: тему (склад, пляж, офис, кухня, фестиваль, сцена, консерватория, спортзал, зима, переезд;
   с SSR — фэнтези, с UR — космос), одежду, груз, свет, позу и план. Темы, которых в пуле меньше их доли по весу,
   выпадают чаще. Грузчицу выдаёт абсурдный груз, а не униформа; черты архетипа (`traits` в `archetypes.json`)
   сохраняются в любом образе. К промпту всегда добавляются модификатор редкости, оговорка «adult woman, 21+»
   и негатив; школьная форма запрещена. Результат — WebP 768×1024 и превью 240×320.
3. **Автомодерация** — vision-модель (Gemini Flash Lite) смотрит картинку и текст. Детские черты, NSFW,
   дискриминация, возраст на вид < 18 — в брак; сомнения (возраст на вид < 21, реальный человек, бренд,
   водяной знак) — на ручную проверку в админке. В пул попадает только `ready`.

Перед каждым вызовом проверяется лимит (по умолчанию 100 ₽ в сутки и 1500 ₽ в месяц, сутки по Москве).
Каждый вызов пишется в `ai_generation_log` с ценой в рублях. Если ИИ выключен, лимит исчерпан или RouterAI
недоступен, игра продолжает выдавать процедурных waifu из запаса (40 на каждую ИИ-редкость).

Стоимость на октябрь 2026: около 4,6 ₽ и 25–50 секунд на одну waifu (текст около 0,1 ₽, портрет 4,4 ₽,
модерация 0,08 ₽). При лимите 100 ₽ в сутки это примерно 20 waifu в день, полный пул из 120 набирается за 6 дней.

**Админка «ИИ-цех»** (видна только админам):

- сводка: расходы, доля прошедших валидацию, вердикты модерации, наполнение пула;
- настройки: модели и резервные модели (списки из каталога RouterAI), температура, таймауты, промпты,
  модификаторы редкостей, лимиты, размер пула; каждое сохранение — новая версия с откатом;
- кнопка «Тест»: одна пробная waifu текущими настройками с JSON, портретом, временем и ценой (в пул не попадает);
- модерация: очередь на ручную проверку и отклонённые;
- журнал вызовов.

Разовая тестовая генерация из консоли:

```bash
cd workers && PORTRAITS_DIR=../data/portraits npx tsx src/ai-test-once.ts SSR gym_philosopher
# сравнение вариантов стиля: стили × персонажи с одним seed → data/ai-test/styles/sheet.jpg
cd workers && npx tsx src/style-test.ts
```

## Ключевые решения

- **Расчёт прогресса — только на сервере.** Каждое действие сначала «доводит» состояние игрока до текущего
  момента (`advance`: блокировка строки, онлайн-окно 90 с, офлайн до 12 ч с эффективностью 50–100%),
  затем применяется в той же транзакции. Клиент лишь интерполирует цифры 10 раз в секунду.
- **Дубликат** — waifu того же архетипа и той же редкости, что уже есть у игрока (10 архетипов × 5 редкостей = 50
  уникальных слотов коллекции). Дубликат превращается в Осколки душ, которые идут на звёзды.
- **Процедурный пул** — тексты из шаблонов архетипа, портрет — вариация базового (оттенок, насыщенность,
  зеркало). Он целиком покрывает N и R и служит запасом для ИИ-редкостей; при выдаче ИИ-waifu идут первыми.
- **Итоговые шансы с учётом pity** считаются аналитически (стационарное распределение марковской цепи)
  и показываются в игре рядом с базовыми.
- **Мат**: тексты помечены уровнем 0/1/2; в настройках — выкл / умеренный (по умолчанию) / жёсткий.

## Баланс (`economy-1.2.0`)

Ориентир из ТЗ — первый престиж за 3–6 часов активной игры. Печати: `floor((груз смены / 1e9)^0.5)`.
Симулятор непрерывной игры (300 игроков): медиана 5,5 ч, p10–p90 = 2,5–10,5 ч. Хардкор с сессиями
набирает 1e9 кг за 1,1–4,7 активных часа (медиана 2,9 ч). Казуалы доходят за счёт офлайна.
Полный отчёт — [`docs/sim-progress.txt`](sim-progress.txt).

## M6 — полировка

Интерфейс на русском и английском (настройка «Язык»). Игровые тексты — имена, био, достижения, контракты — остаются русскими.

Звуки — короткие сигналы WebAudio, без файлов: призыв, успех работы, золотое достижение (на него ещё вспышка). Выключаются в профиле. До первого касания браузер может их блокировать.

PWA: манифест, иконка, service worker (оболочка network-first, портреты из кэша, API не кэшируется). `theme-color` следует за темой.

Воронка в админке, вкладка «Сводка»: `registration`, `first_pull`, `first_prestige`, `first_achievement`. Закрытая бета — вход только по инвайту, 18+.

## M5 — события, достижения, мерч

Достижения считаются на сервере при каждом тике. Награда (жетоны, билеты, косметика) пишется один раз: повторный запрос упирается в первичный ключ и ничего не начисляет. Так же устроены покупка в магазине, веха события и ежедневное задание.

Недельный рейтинг — груз, набранный с понедельника по Москве. Событие «Неделя пианино» (12–26 октября 2026) считает успешные контракты на пианино. На складе иногда всплывает мини-выбор. Портрет можно перегенерировать один раз за жетоны; при сбое жетоны возвращаются.

## Сток портретов и ИИ

Портреты пула берутся из `server/assets/portraits/stock`: три кадра на каждый архетип во всех пяти редкостях (150 штук). Фоновый воркер RouterAI для этих картинок по умолчанию не запускается. Платную генерацию можно снова включить в админке.

## M4 — менеджмент

Восемь зданий: Склад, Столовая, Автопарк, Спортзал, Диспетчерская, Общежитие, Магазин мерча, Баня/Курилка.
Вехи ×2 на 25/50/100 и далее каждые 100 — у всех.

- **Тренировки.** Спортзал даёт места (1–4) и ускорение. Типы: силовая, кардио, вежливость, удача, ОФП.
  Длительность от 1 минуты до 8 часов. Опыт кормит уровни, статы копятся в `stat_bonus` (потолок 30% бюджета редкости).
  Редкий «провал» без потерь, редкий «great» с удвоенным опытом и статом. Waifu на тренировке уходит со склада.
- **Контракты.** Диспетчерская: доска 3–6 заказов и 1–4 одновременных. Команда 1–3. Шанс от мощности, ключевого стата,
  удачи и усталости; провал платит 35%. Награда масштабируется от `coinsPerSec`. Теги груза завязаны на таланты `contract_bonus`.
- **Усталость.** 0–100, копится от тренировок и контрактов, снижает их успех, склад не трогает. Баня ускоряет восстановление,
  Столовая уменьшает прирост. Ленивое хранение: значение + метка времени.
- **Престиж «Конец смены».** Сброс монет, протеина, зданий, уровней/опыта waifu и груза смены. Остаются коллекция,
  звёзды, осколки, билеты, бонусы статов, печати и дерево. Формула печатей — от груза смены (`player_state.cargo`).
  Каждая заработанная печать даёт +10% к грузу и монетам; дерево покупается тратой печатей.
  «Диспетчер на автомате» забирает готовые тренировки и контракты в `advance`; «Прораб» автоулучшает здания
  (до половины монет, самое дешёвое улучшение).
- Контент: `config/flavor.m4.ru.json`, `config/contracts.json` (30 клиентов, 40 грузов).
