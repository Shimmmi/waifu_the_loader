# Waifu Movers / Грузчицы Inc.

Браузерная gacha-инкрементал игра 18+ для закрытого круга. ТЗ — [`docs/tz.md`](tz.md).
Прод: <https://shimmirpgbot.ru/waifu_loader/> (вход по инвайт-коду).

Готовы этапы **M1** (склад, ресурсы, 3 здания, 10 заготовленных waifu, серверные тики и офлайн-прогресс)
и **M2** (баннеры, pity, пул waifu, дубликаты → Осколки душ, коллекция и карточки).

## Структура

| Папка | Что внутри |
|---|---|
| `shared/` | Типы, zod-схемы, формулы экономики, gacha и pity, процедурный генератор профилей, тесты |
| `server/` | Fastify API, миграции PostgreSQL, авторизация, серверный расчёт прогресса |
| `workers/` | BullMQ: пополнение пула waifu (`TextProvider` / `ImageProvider`, до M3 — процедурные) |
| `client/` | React + Vite + Zustand, PWA |
| `config/` | Версионируемые JSON-конфиги баланса и контента (хэш пишется в `config_versions`) |
| `scripts/` | Валидатор контента, симулятор призывов, симулятор прогресса |
| `deploy/` | Dockerfile, docker-compose, конфиг Nginx, `deploy.sh`, `backup.sh`, `invite.sh` |

## Локальная разработка

Нужны Node ≥ 18.19 и Docker.

```bash
npm ci
cp .env.example .env            # заполнить POSTGRES_PASSWORD, COOKIE_SECRET и DATABASE_URL
docker compose --env-file .env -f deploy/docker-compose.yml up -d postgres redis

# API (миграции применяются при старте, заготовленные waifu попадают в пул)
cd server && SERVE_STATIC=1 PORTRAITS_DIR=../data/portraits npx tsx src/index.ts
# пул waifu: воркер раз в 60 с или разово
cd workers && npx tsx src/index.ts       # или: npx tsx src/refill-once.ts
# клиент: http://127.0.0.1:5180/waifu_loader/
npm run dev:client

npm run invite -- create 10 "тест"       # инвайт-код
```

Проверки (их же запускает GitHub Actions):

```bash
npm run lint && npm run typecheck && npm run validate -w scripts && npm test
npm run sim:gacha                         # 1 млн призывов, сверка с шансами ±0.2%
npm run sim:progress -- 10000 30          # 10 000 игроков × 30 дней
```

## Почему Docker Compose

На VPS уже живут другие сайты и их сервисы. Отдельный compose-проект `waifu_loader` со своими PostgreSQL и Redis:

- не трогает чужие базы, версии и настройки (свой Postgres 16, свой Redis с `noeviction` под очередь BullMQ);
- все порты слушают только `127.0.0.1` (API 8040, Postgres 5440, Redis 6390), наружу смотрит только Nginx;
- обновление и откат — пересборка одного образа, состояние лежит в именованных томах и `data/`;
- ограничения памяти на контейнеры не дают игре съесть ресурсы соседей.

## Деплой

```bash
./deploy/deploy.sh
```

Скрипт делает `git pull`, собирает образ, поднимает контейнеры, копирует статику клиента в `data/www`,
ждёт `/api/health`, проверяет `nginx -t` и перезагружает Nginx.

Один раз вручную:

1. В 443-блок `server` сайта `shimmirpgbot.ru` (`/etc/nginx/sites-enabled/waifu-bot`) добавить
   `include /opt/Waifu_Loader/deploy/nginx/waifu_loader.conf;`. Все location в файле с префиксом
   `^~ /waifu_loader/`, остальные пути сайта не затрагиваются.
2. Бэкапы — в cron root: `30 4 * * * /opt/Waifu_Loader/deploy/backup.sh >> /var/log/waifu_loader_backup.log 2>&1`.
   Дамп PostgreSQL и архив портретов пишутся в `/var/backups/waifu_loader`, хранятся последние 7 копий.

Инвайты на проде:

```bash
./deploy/invite.sh create 5 "друзья"     # код на 5 активаций
./deploy/invite.sh list
./deploy/invite.sh admin "Ник"           # права админа (пригодятся в M3 для админки ИИ)
```

## Секреты

Все секреты — только в `.env` (в `.gitignore`). В репозитории лежит `.env.example` с пустыми значениями.
Ключ RouterAI (M3) живёт только на сервере и никогда не отдаётся клиенту.

## Ключевые решения

- **Расчёт прогресса — только на сервере.** Каждое действие сначала «доводит» состояние игрока до текущего
  момента (`advance`: блокировка строки, онлайн-окно 90 с, офлайн до 12 ч с эффективностью 50–100%),
  затем применяется в той же транзакции. Клиент лишь интерполирует цифры 10 раз в секунду.
- **Дубликат** — waifu того же архетипа и той же редкости, что уже есть у игрока (10 архетипов × 5 редкостей = 50
  уникальных слотов коллекции). Дубликат превращается в Осколки душ, которые идут на звёзды.
- **Пул waifu до M3** — процедурный: тексты из шаблонов архетипа, портрет — вариация базового (оттенок, насыщенность,
  зеркало). Интерфейсы `TextProvider` / `ImageProvider` готовы под `RouterAiProvider`.
- **Итоговые шансы с учётом pity** считаются аналитически (стационарное распределение марковской цепи)
  и показываются в игре рядом с базовыми.
- **Мат**: тексты помечены уровнем 0/1/2; в настройках — выкл / умеренный (по умолчанию) / жёсткий.

## Баланс (`economy-1.1.0`)

Ориентир из ТЗ — первый престиж (M4) за 3–6 часов активной игры, а Печати начисляются с 1e9 кг груза.
По симулятору прогресса (10 000 игроков × 30 дней) хардкорный игрок набирает 1e9 кг за 2,1–8,4 активных часа
(медиана 4,7 ч). Казуалы и обычные игроки доходят до 1e9 в основном за счёт офлайна, при 0,3–1 активном часе.
Первая SSR+ в первый день выпадает у 59–68% игроков, к концу недели — почти у всех.
После ~100-го уровня зданий рост упирается в экспоненту цен — это место для престижа (M4).
Полный отчёт по 10 000 игроков — [`docs/sim-progress.txt`](sim-progress.txt).
