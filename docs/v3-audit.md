# Этап 0. Godot-текст / v3 / текущий код

Репозитория Godot на диске нет. Колонка Godot — письменное ТЗ [`info/ТЗ «Терминал „Тупик-9“» пиксельная IDLE-игра на Godot для itch.io.md`](../info/ТЗ%20«Терминал%20„Тупик-9“»%20пиксельная%20IDLE-игра%20на%20Godot%20для%20itch.io.md). Числа v3 в `config/v3/` — заглушки до правки этого отчёта. Списки §3 в код подставлены как есть и списками Godot не заменены.

## Сущности

- Расы. Godot: 5 видов (кожаные, кремнийцы, жестянки, желейники, пернатые). v3: 8 рас (`terran` … `inferni`). Код до v3: рас нет, 10 архетипов в `config/archetypes.json`.
- Классы. Godot: 6 (грузчик, водитель, крановщик, кладовщик, механик, бригадир). v3: 8 (`loader`, `forklift`, `crane`, `stocker`, `dispatcher`, `mechanic`, `guard`, `medic_cook`). Код: `native_class` из статов, только `loader/driver/crane/clerk`.
- Статы. Godot: `str/agi/acc/end/wit`. v3: `str/spd/acc/end/cha/lck`. Код: `str/end/spd/cha/lck`.
- Редкость. Godot: 0…4, черты 0–1 / 1 / 2 / 2 / 3. v3: обычная…легендарная, слоты и окно R из §5.5. Код: `N/R/SR/SSR/UR`, таланты 1–3 без знака.
- Трейты. Godot: 12 положительных, 8 нейтральных, 4 скрытых. v3: 28 со знаком и tier. Код: положительные таланты `config/talents.json`.
- Выработка. Godot: узкое место станций, т/мин. v3: `(СИЛ×0,5+СКР×0,3+ТЧН×0,2)×class_mult×(1+синергии)`. Код: кг/с от power и, при флаге терминала, линия тонн/мин.
- База. Godot: сетка секторов, расширение = новый сектор. v3: шахта, этаж из 3 ячеек, 14 построек §6.2. Код: панорама секторов в `shared/src/terminal.ts` и отдельно idle-здания.
- Найм. Godot: биржа кандидатов. v3: ролл за звёзды, шаблон портрета. Код: ролл за билеты, дубль = осколки, ключ архетип×редкость.
- Валюты. Godot: центы и запчасти. v3: кредиты, звёзды, наследие. Код: монеты, протеин, билеты, жетоны, осколки, печати.
- Вкладки. Godot: терминал, бригада, найм, контракты и дальше по рангу. v3 §9: те же шесть имён в `config/v3/ui.json`. Код: склад, здания, коллекция, гача, тренировки, контракты, престиж, события, достижения, магазин, профиль.

## Расхождения с §3 и §6.2, которые не схлопнуты

Приоритет Godot из §0 не применён: авторского репозитория нет, а письменные списки ломают 8×8, шахту и ролл. До правки отчёта играбельные данные — заглушки v3.

## Миграция (черновик на утверждение)

Редкость: `N` обычная, `R` необычная, `SR` редкая, `SSR` эпическая, `UR` легендарная.

Раса ветерана: `terran`. Класс:

- `fridge_quiet`, `goth_packer` → `stocker`
- `gymnast_rigger`, `gym_philosopher` → `loader`
- `sleepy_piano`, `retired_waitress` → `medic_cook`
- `shout_commander` → `dispatcher`
- `dreamy_courier`, `forklift_accountant` → `forklift`
- `tape_maniac` → `mechanic`

Курс в `config/v3/migration.json`: 1 осколок = 1 звезда. Уже купленный ранг копируется в `star_rank`, конвертируется только остаток осколков.

## Схемы

Игра проверяет JSON через zod (`shared/src/v3/schema.ts`) и не стартует с битым файлом. Тот же набор полей описан в [`docs/v3/content.schema.json`](v3/content.schema.json) для обмена с Godot.

Промпты v0.3 лежат в [`docs/prompts/`](prompts/README.md) без правки текста.
