# Сюжетные реплики

Здесь все тексты, которые игра показывает в окне сюжета. Игра читает их из `config/v3/locale.ru.json` по ключу. Этот файл — черновик для правки.

Кто говорит:

- герой — в окне подставляется имя игрока
- корпорация — бывший работодатель
- соперник — филиал напротив

Кнопки в окне:

- **Дальше** показывает следующую реплику, если она уже стоит в очереди
- **Пропустить** закрывает всю оставшуюся очередь, награды вехи при этом уже выданы
